# Predicting Stock Price Movement from Financial News Sentiment

This project explores how financial news sentiment impacts stock price movement using exploratory data analysis (EDA), text analysis, and technical indicators.

## Project Structure

- **data/**: Raw and cleaned datasets
- **notebooks/**: Jupyter notebooks for EDA and visualization
- **eda/**: Python scripts for descriptive stats, time series, and text analysis
- **src/**: Source code modules
- **tests/**: Placeholder for unit tests

## Task 1: Exploratory Data Analysis (EDA)

- Cleaned and parsed financial news data
- Extracted publication date, publisher, and headlines
- Visualized trends over time and by publisher
- Analyzed word frequency and sentiment distribution

## Task 2: Technical Indicator Analysis (Coming Next)

- Calculate indicators using TA-Lib (e.g., RSI, MACD, moving averages)
- Analyze stock prices with PyNance
- Visualize impact of indicators on price trends
